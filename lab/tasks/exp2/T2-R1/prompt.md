다음 요청을 처리해 줘.

관리자 화면에 "처리 지연 환불" 목록을 추가해 줘.

- 화면 경로: `/refunds/stale`
- 화면 제목: "처리 지연 환불"
- 메뉴: "환불" 그룹, 항목 이름 "처리 지연 환불"
- 권한: 화면과 API 모두 `REFUND_READ`
- API: `GET /api/admin/refunds/stale`. 응답은 `GET /api/admin/refunds` 와 같은 환불 객체의 배열
- 조건: 상태가 `REQUESTED` 이고, 요청 시각이 현재 시각에서 2일을 뺀 시각보다 이전인 환불. 같은 시각은 넣지 않는다. 현재 시각은 애플리케이션의 `Clock` 시각이다
- 정렬: 요청 시각 오름차순, 같으면 ID 오름차순
- 표의 열: ID, 주문 ID, 요청 금액, 요청일시. 값의 표시 형식은 기존 목록 화면과 같다
- 버튼은 없다
