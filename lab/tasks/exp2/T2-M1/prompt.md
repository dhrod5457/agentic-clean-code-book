- 화면 제목: "휴면 회원"
- 메뉴: "회원" 그룹, 항목 이름 "휴면 회원"
- 권한: 화면과 API 모두 `MEMBER_READ`
- API: `GET /api/admin/members/dormant`. 응답은 `GET /api/admin/members` 와 같은 회원 객체의 배열
- 조건: 상태가 `ACTIVE` 이고, 마지막 로그인 시각이 현재 시각에서 365일을 뺀 시각과 같거나 그보다 이전인 회원. `SUSPENDED` · `WITHDRAWN` 회원은 넣지 않는다. 현재 시각은 애플리케이션의 `Clock` 시각이다
- 정렬: 마지막 로그인 시각 오름차순, 같으면 ID 오름차순
- 표의 열: ID, 이름, 이메일, 등급, 마지막 로그인. 값의 표시 형식은 기존 목록 화면과 같다
