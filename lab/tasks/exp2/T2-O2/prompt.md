관리자 화면에 "고액 주문" 목록을 추가해 줘.

- 화면 경로: `/orders/high-value`
- 화면 제목: "고액 주문"
- 메뉴: "주문" 그룹, 항목 이름 "고액 주문"
- 권한: 화면과 API 모두 `ORDER_READ`
- API: `GET /api/admin/orders/high-value`. 응답은 `GET /api/admin/orders` 와 같은 주문 요약 객체의 배열
- 조건: 결제 금액(`totalAmount`, 상품 금액 + 배송비)이 500,000원 이상인 주문. 주문 상태와 관계없이 넣는다. 현재 시각은 애플리케이션의 `Clock` 시각이다
- 정렬: 결제 금액 내림차순, 같으면 ID 내림차순
- 표의 열: ID, 회원 ID, 상태, 결제 금액, 주문일시. 값의 표시 형식은 기존 목록 화면과 같다
- 버튼은 없다
